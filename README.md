# FCUP-EPIDEMIOLOGY

**Consumo Habitual de Cafeína e o Risco de Doença de Parkinson: Protocolo de um Estudo Caso-Controlo nas ULSs de Santo António e São João**

Trabalho final da Unidade Curricular de Epidemiologia, Licenciatura em Bioinformática (3.º ano, 2026/2027).

📄 **Versão web (protocolo + anexo, com ligações):** https://amarcos20.github.io/FCUP-EPIDEMIOLOGY/
Para obter um PDF, abrir a página e usar o botão **Guardar PDF**.
